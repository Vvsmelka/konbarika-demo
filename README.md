# Konba Rika · demo web

Demo de la web de Konba Rika (Barrika, Bizkaia): portada en vídeo, cartelera, carta con QR por mesa, rincones, galería y reservas.

- `index.html` — la web
- `carta.html?mesa=12` — carta digital del QR de mesa
- `equipo.html` — panel de equipo (los cambios se guardan solo en el navegador)
